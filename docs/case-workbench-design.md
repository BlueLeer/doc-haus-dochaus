# 案件工作台界面整理

- 顶部概览展示版本、记录数、待确认数、来源需复核数。
- 分类导航带记录数量；记录头突出标题和确认状态。
- 基础表单、来源核验、证据缺口、关联记录、确认操作分区。
- 控件统一为 42px 高；自定义下拉菜单复用页面颜色、边框和字号。
- 下拉框支持方向键、Home/End、回车、Escape、Tab 与外部点击关闭。
- 复选框与首行文字对齐，长文本换行不挤压勾选框，整行标签可点击。
- 窄屏表单降为单列，导航与概览改为两列；样式限定在工作台内。

验证：前端类型检查及生产构建通过；使用 P2 虚构案件浏览器检查下拉菜单、
键盘选择、点击关联记录文字切换复选框；测试后恢复原值，保存按钮重新禁用，
未写入案件数据。后端与案件数据格式不变。
