# 手动案情录入

交付日期：2026-09-06。

## 使用流程

案件工作台展开「手动录入案情」，按字段填写文本，选择陈述立场，点击「解析并预览」。核对并勾选需要的概况、时间轴条目，点击「加入所选条目草稿」，最后点击工作台「保存修改」。加入草稿不等于已经持久化。

建议每行一项，例如：

```text
乙方劳动者：张三
甲方单位：重庆某公司
工作年限：5年
基本工资：8000元/月
入职日期：2020年3月1日
离职日期：2025年3月1日
工作地点：重庆市渝中区
```

## 能力与边界

- 使用确定性的本地标签解析，不调用外部模型，不是任意长篇叙述的语义提取器。
- 支持劳动者、用人单位、工作年限、工资组成、工作地点、入离职和部分程序日期等标签；也接受「2020年3月1日入职」等简单日期事件。
- 日期项同时生成概况与时间轴；工作年限不反推出入离职日期，不视为法定补偿年限计算结果。
- 所有条目默认待确认、无材料来源，证据缺口中保留录入原话。甲乙方身份映射需要承办人核对。
- 未识别片段显示在预览中；不完整或无效日期不生成假日期。不同工资等冲突说法保留为不同记录。
- 加入时跳过种类、字段、内容、日期及立场一致的重复记录，不覆盖既有记录。
- 手动记录沿用工作台 replace 保存；没有放宽智能体 propose 模式的材料来源要求。
