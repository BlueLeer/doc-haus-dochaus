# 案件工作台：紧凑阅读与连续核对

交付日期：2026-09-06。目标是减少每条记录常驻完整表单造成的阅读和编辑成本，不改变后端案件格式、来源核验和版本冲突机制。

## 已实现

- 四类记录统一为紧凑列表，长内容默认两行；点击字段或内容在右侧打开完整编辑面板。
- 列表与详情独立滚动。关闭详情保留本地修改；Esc 关闭详情，展开的下拉框优先响应 Esc。
- 案件概况上方展示劳动者、单位、入离职日期、基本工资、工作年限摘要。缺失字段可直接补充；同字段多条记录显示条数，点击筛选后逐条核对，不合并冲突。
- 时间轴排序保留未知日期，未知日期区有标识；日期与事实内容可行内快捷添加，日期允许空白。
- 搜索标题、内容、日期、缺口和来源文件；筛选待确认、存在争议、缺少来源、来源需复核。
- 全选仅针对当前筛选结果。批量确认、设为待确认、调整立场；调整立场同时撤回确认状态。批量确认显示条数和风险提示。
- 详情提供「确认并查看下一条」，推进到当前筛选列表中后续待确认记录。缺来源、存在争议、来源变化时先提示；普通单条核对不额外弹确认框。
- 顶部固定保存工具栏，显示新增、修改、删除合计未保存条数。加入、确认、移除仍需显式保存。
- 手动解析预览改为紧凑纵向列表并限制高度；主录入入口默认折叠。
- 宽屏放宽工作台父容器宽度，小屏改为上下列表与编辑面板；不会改变其他页面容器宽度。
