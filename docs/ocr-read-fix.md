# 文档全文读取连接中断修复

上传、全文读取、案件引文核验共用 `.dochaus/text-cache` 原始提取全文缓存。
键包含文件内容 SHA-256、扩展名及提取配置版本；内容变化自动重新提取。
缓存保留在案件本地目录中，包含敏感原文，按案件材料管理；不是新的案件事实记录。
并发相同读取共用一次提取，失败不缓存，写入采用临时文件原子替换。
每次使用仍执行既有规范化与注入检测流程，不从分块索引拼接全文。

首次识别的服务空闲等待上限设为 255 秒；扫描页转图长边限制为 3508
像素，避免手机 PDF 的超大物理页面在 300 DPI 下生成万像素图片。
极长文档仍可能超过等待上限，本次未实现异步 OCR 作业队列。

回归：在 services/ingest 运行 bun test（90 项通过）及 bun run typecheck。
覆盖缓存复用、并发合并、内容变化失效、失败后重试和真实中文扫描样本。
